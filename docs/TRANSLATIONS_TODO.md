# Translations to do

SchoolDimes supports English (`en`), Luganda (`lg`) and Kiswahili (`sw`).
Per the project rule, **no translation is invented**: where a native-speaker
translation isn't known, the English text is used and the key is listed here.
Send these to native speakers for translation and review before a pilot.

## Backend (Django, `backend/locale/`)

- **Notification templates** (`backend/notifications/translations.py`): Part 2
  wrote lg and sw versions of every notification. They were **not reviewed by
  a native speaker**; review all of them.
- **Error messages** (`gettext`) added in Parts 2 and 4A: there are no lg/sw
  catalogs for them, so they show in English. New in Part 4A:
  - "card_uid must be 4-32 bytes of hex, e.g. 04:A2:2B:7C:91:3E:80"
  - "A card with this card_uid already exists."
  - "A lost card can't get a new PIN; reissue it instead."
  - "Only school or platform admins review verifications."
  - "No parent account with that email." / "Only admins can look up accounts."
  - "Only admins manage staff accounts." / "You can't deactivate your own account." / "Password updated."
  - "Staff accounts can be canteen_staff, merchant_staff or school_admin." / "A school is required for this role." / "Merchant staff must be linked to a merchant." / "An account with this email already exists."
  - "Only parent accounts can be linked as guardians."
  - "This student already has a portal login." / "This student has no portal login." / "Only student portal accounts can use this page." / "An email and a password of at least 8 characters are required."
  - "Student portal accounts can only use the student portal."
  - "Only parents have a parent dashboard." / "Dates must be YYYY-MM-DD."
  Run `docker compose exec web python manage.py makemessages -l lg -l sw` to
  collect them into `.po` files for the translators.

## Web surfaces (`backend/web/`, Django templates)

The web UI moved from the Next.js dashboard to Django templates. The Next.js
`messages/lg.json` and `sw.json` were empty, so **no Luganda or Kiswahili UI
translation exists yet**; every string below shows in English in lg/sw.

How it works: `docker compose exec web python manage.py build_locale` collects
every `{% translate %}` / `{% blocktranslate %}` / `_()` string under
`backend/web/` into `backend/locale/{lg,sw}/LC_MESSAGES/django.po` (section
"Web surfaces", empty `msgstr` = English fallback). To add a reviewed
translation, put it in `backend/web/core/translations.py` (`LG` / `SW`, keyed by
the English text below) and re-run `build_locale`; it is compiled into the `.mo`
file. Placeholders such as `%(name)s` must be kept as they are.
